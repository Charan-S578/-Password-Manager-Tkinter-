# Password Manager (Tkinter)

This Python project is a Password Manager GUI built using Tkinter. It helps users generate strong random passwords, save website credentials, and store them securely in a local file. It also includes clipboard copying, input validation, and confirmation dialogs for safe data entry.

---

## 📌 Features

- Random strong password generator
- Automatic clipboard copy using pyperclip
- Save website, email, and password details
- Input validation with warnings
- Confirmation dialog before saving
- Simple and user-friendly GUI

---

## 🛠 Technologies Used

- Python 3
- Tkinter GUI Library
- Random module
- Pyperclip module
- Messagebox (Tkinter)
